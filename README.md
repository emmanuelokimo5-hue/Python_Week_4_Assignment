# PLP Python Week 4 - Functions & Toolbox

- `welcome.py` - Contains a welcome function that creates greetings for different names.
- `toolbox.py` - Contains three functions for doubling numbers, checking pass scores, and creating greetings.

The `greet` function was the hardest to write because it uses a default parameter. I had to understand how Python uses `"Hello"` when no greeting is provided and uses the given greeting when one is provided.
